
There are many linux commands, but as a beginner these are some basic commands that are useful to practice regularly.

Getting comfortable with simple commands first makes linux much less confusing later.

pwd ----→ shows current location

ls ---→ shows files and folders

cd Downloads ---→ used to enter folders

cd .. ---→ moves one folder back

mkdir practice ---→ creates folder

touch notes.txt ---→ creates empty file

cat notes.txt ---→ shows file content

nano notes.txt ---→ opens file editor

clear ---→ cleans terminal

whoami ---→ shows current username

ip a ---→ shows ip address

history ---→ shows previous commands

rm file.txt ---→ deletes file

cp file.txt backup.txt ----→ copies file

mv old.txt new.txt ----→ moves or renames file

sudo apt update ---→ updates package list
